# Datadog Toto 2.0 22m 验收计划

## 原始测试集与官方/公开指标

官方 22m 模型卡的 BOOM CRPS 0.363、MASE 0.601；该聚合指标需要 BOOM 完整协议，不能用 ETTh1 的 MSE/MAE/WQL 代替。 来源：https://huggingface.co/Datadog/Toto-2.0-22m/blob/685e4ae3e2be8d8998025e53dd98e7fdcb296a89/README.md

输入 `[batch,variates,512]`，输出 `[batch,variates,horizon]` 中位数及九个分位数；本入口仅支持全部观测值有限的输入，不自动把缺失值置为已观测。 22m、4m 和 Toto 1.0 的权重与输出不同；ETTh1 未覆盖缺失、变长和多分块场景。WQL 是本输入集合的均值分位损失，分母为目标绝对值之和，不是 BOOM 聚合 CRPS。

## 功能验证

固定源码/依赖/权重/config/辅助 head 及 SHA；完成真实输入、设备、输出形状和缺失依赖失败验证。分别运行 NPU 和显式 CPU，保存同输入、同模型、同 head 的结果；阈值由真实验收要求决定。

## L2 精度与性能

完整数据集及正确 evaluator、预后处理/标签范围对齐后比较任务指标；没有可比公开指标时按相同数据和权重使用 CPU 结果辅助对齐。NPU 设备同步测量至少三次独立运行，取中位数，分别统计纯模型、端到端、峰值显存。禁止用 CPU 性能推算加速比或以 fixture 当任务精度。

## 最低正式验收与报告模板

记录目标卡型、驱动、CANN、Python、torch/torch_npu、上游和权重 SHA、数据/标签 SHA、命令、样本数、精度、数值误差、三次性能及不可比项。正式候选需通过目标仓贡献门禁及干净目录完整重放；当前 NPU 验证、完整数据精度、性能及 clean-room 均未执行。

## 本轮工具回归与剩余正式门禁

2026-10-27：本目录 13 项离线回归通过（包括异常输入、结果一致性和性能报告负向测试），不构成真实模型或 NPU 验收。推理成功后保存 `<输出文件>.performance.json`；按 README 独立执行至少三次并用 `performance.py --runs ... --output ...` 汇总，检查相同模型/数据/设备/参数及独立运行 ID。至少保留一次完整数据的精度评测，性能子集与完整质量评测必须明确区分。

最低正式补验：选定对外卡型及配套镜像/CANN/驱动 → 固定权重和数据校验 → 干净安装并导入模型 → 真实 CPU/NPU 功能和声明范围质量对齐 → 有依据阈值的 compare → 三次 NPU 性能报告 → 端到端/首次编译/HBM → 目标仓正式自测和独立候选完整重放。演示阈值不能升级为验收门槛，缺任一实测项均保留待验收。
